# Epic 04: Usage Tracking & Recording

## Description
Captures and maintains stationery usage data at the branch level across all 1,500 branches, enabling item-wise consumption tracking with quantities, timestamps, and contextual notes. Supports both branch-level and regional-office-level usage aggregation for comprehensive visibility into stationery consumption patterns across the entire organization.

## Business Objective
Provide accurate, timely visibility into stationery consumption across all branches and regional offices to support inventory planning, cost control, and resource allocation decisions.

## Scope
**Included:** Usage record creation and management, item-wise usage tracking, branch-level usage data filtering and totaling, regional-office-level usage aggregation including all associated branches, quantity tracking per item per branch, usage date and notes capture.

**Excluded:** Real-time inventory deduction (BRD assumes manual or periodic data entry), automated stock replenishment (per BRD Out of Scope), barcode scanning for usage entry (per BRD Out of Scope).

## Acceptance Criteria
- [ ] Users can create and view usage records capturing item, branch, quantity, and date
- [ ] Usage data can be filtered and viewed for specific individual branches
- [ ] Branch-level usage totals are calculated correctly for selected items
- [ ] Regional-office-level usage data aggregates all associated branch consumption
- [ ] Usage records capture quantity, usage date, and optional notes

## Definition of Done
- All features under this epic are complete and accepted
- All acceptance criteria above are verified
- No known defects in the usage tracking and recording functional area
